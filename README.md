# Course_work_4 — Сервис управления рассылками сообщений

Веб-приложение на Django для управления email-рассылками.

## Функционал

- Полный CRUD для клиентов, сообщений и рассылок
- Ручная отправка рассылок
- Автоматическая отправка по расписанию (django-apscheduler)
- Главная страница со статистикой
- Регистрация с подтверждением по email
- Восстановление пароля
- Ограничение доступа по владельцу
- Роль "Менеджер": просмотр всех данных, блокировка пользователей, отключение рассылок
- Кэширование через Redis
- Логирование событий и ошибок
- Безопасность: SECRET_KEY, email-настройки в .env

## Технологии

- Django 6.0
- Bootstrap 5
- Redis
- django-apscheduler
- python-dotenv

## Запуск

1. Установить зависимости: `pip install -r requirements.txt`
2. Запустить Redis
3. Создать `.env` файл (пример в репозитории)
4. Применить миграции: `python manage.py migrate`
5. Создать суперпользователя: `python manage.py createsuperuser`
6. Запустить: `python manage.py runserver`

Открыть http://127.0.0.1:8000/

## Безопасность

SECRET_KEY и настройки email вынесены в `.env` (не включён в репозиторий).

Проект выполнен полностью по ТЗ (Часть 1 и Часть 2 + дополнительные задания).
